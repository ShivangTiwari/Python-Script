# Inbox Delivery Test (IDT) Tool

The Inbox Delivery Test (IDT) tool is designed to automate the process of checking the inbox delivery rate of various Mail Transfer Agents (MTAs). This tool utilizes Python scripting with SMTP and IMAP libraries to send emails from a specified email address to multiple recipients and subsequently verify if the emails reached their respective inboxes.

## Overview

The backend logic of the IDT tool involves two primary functionalities:

1. **Email Sending (SMTP):** The tool uses the SMTP library to send emails from a specified email address provided on the user interface to various recipients' email addresses stored in the backend.

2. **Inbox Verification (IMAP):** After sending the emails, the tool logs into each recipient’s email account using the IMAP library to verify if the email with the same subject has reached the inbox or not. This automated process eliminates the need for manual verification.

## Workflow

1. The user specifies the sender's email address and the recipients' email addresses via the user interface (UI).
2. The tool sends emails using the SMTP library to multiple recipients.
3. It logs into each recipient's email account using the IMAP library.
4. The tool checks if the email with the specified subject has reached the inbox.
5. Results are logged and presented to the user, showcasing the delivery performance of different MTAs.

## Benefits

- **Automation:** Eliminates the need for manual verification, ensuring efficient monitoring of inbox delivery rates.
- **Scalability:** Capable of handling a large number of emails and MTAs.
- **Insights:** Provides accurate insights into the delivery performance of different MTAs.

## Usage

1. Clone the repository containing the IDT tool.
2. Install necessary Python libraries (SMTP, IMAP).
3. Run the Python script providing necessary parameters such as sender's email address, recipient's email addresses, etc.
4. Review the results generated by the tool to analyze the inbox delivery rates of different MTAs.
